# Code of conduct

We want this to be a welcoming project for everyone who wants to improve it.

**Expected behaviour**

- Be respectful and assume good faith.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

**Unacceptable behaviour**

- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Using the project to build tools for abusing websites or services (for example by evading their protections).

**Enforcement**

Maintainers may edit or remove comments, commits, issues and other contributions that do not follow this code, and may
ban contributors who repeatedly or seriously violate it. Report concerns privately to the maintainers through the
repository's security advisory feature or the contact listed on the maintainers' profiles.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
